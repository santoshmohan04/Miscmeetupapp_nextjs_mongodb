# Miscmeetupapp_nextjs_mongodb

Modern meetup discovery and hosting app built with Next.js, MongoDB, and React Bootstrap.

## Highlights

- Responsive homepage with featured meetups, search, filtering, and sorting
- Rich meetup detail pages with sharing, save, and organizer contact actions
- Improved add/edit flows with validation and modern organizer-focused fields
- MongoDB-backed CRUD operations for meetup management
